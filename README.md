# 英検3級 パスポート

英検3級の合格をめざす、iPad 向けの学習 PWA です。
ビルド不要の素の HTML / CSS / JavaScript（ES Modules）で作っています（漢検4級道場と同じ構成）。

## 主な機能

| 機能 | 内容 |
|---|---|
| 手書きスペル判定 | Apple Pencil・指でつづりを書くと自動で採点。**1マス1文字**で認識するので、単語の自動補正が入らず、まちがえた文字が赤く表示される。4線ノートのマス、1行書き、キーボード（iPad はスクリブルでペン入力も可）から選べる |
| 忘却曲線による出題 | 単語・問題ごとに「記憶の安定度」を記録し、定着度が90%を下回るころに再出題（FSRS 風のモデル）。まちがえたものは同じ回の少しあとにもう一度、以降も早め・多めに出題 |
| スマート単語帳 | 単語675語・熟語159・会話表現64（重要度 A/B/C、例文・訳・不規則変化つき）。フラッシュカード／**高速周回**（スワイプで1枚1秒、周回タイムを記録）／4択／聞いて選ぶ／手書きスペル／ディクテーション |
| 筆記ドリル | 大問1（188問：名詞・動詞・形容詞・副詞・熟語・文法）、大問2 会話文（53問）、大問3 長文（掲示・Eメール・説明文 12題40問）。すべて解説・和訳つき |
| リスニング | 第1部〜第3部（各26問）。ブラウザの読み上げで男女の声を使い分け、本番どおり2回放送。答え合わせでスクリプトを1文ずつ再生 |
| ライティング | Eメール問題12題・英作文20題（模範解答つき）。**無料の自動チェック**（語数・形式・理由2つ・よくあるまちがい約40パターン）と **AI 添削**（英検の観点で点数化・直し・差分表示・模範解答） |
| AI 面接 | 二次試験の流れ（入室→黙読20秒→音読→No.1〜5→退室）を面接官が読み上げ、音声認識で答える。音読の一致率とキーワードで無料採点、AI で詳しい採点も可。問題カード8枚（イラストは SVG で自動生成） |
| AI 解説 | 解説のあとに「AIにくわしく聞く」「AI先生に質問」。回答は端末に保存して再利用（2回目からは無料） |
| 模擬試験 | 本番サイズ（リーディング30問＋ライティング2題 65分 → リスニング30問）、分野別、ミニ模試。中断・再開、CSE スコアの目安、見直し |
| 合格予測 | 直近の正答率から技能別の CSE スコアを換算し、合格ライン（一次1103・二次353）と比べて表示 |
| 文法レッスン | 3級で出る15項目（現在完了・受け身・比較・不定詞・関係代名詞など）。例文の読み上げ・その文法の問題へ |
| 問題をふやす | AI で大問1形式の問題を生成（苦手な単語・文法をねらう）、手持ちの問題（過去問など）を1行1問で取り込み |
| やる気の仕組み | XP・レベル・称号（旅がテーマ）、コンボ、パスポートスタンプ26種、今日のフライトプラン、紙吹雪・効果音（Web Audio で合成） |

## 使い方（iPad）

1. HTTPS で配信されている URL を Safari で開く（下の「公開のしかた」を参照）
2. 共有ボタン →「ホーム画面に追加」
3. ホーム画面のアイコンから起動すると、全画面・オフラインで使えます

- 設定 →「プロフィール」で受検日を入れると、ホームの搭乗券に残り日数が出ます
- 面接の音声認識を使うには、iPad の「設定 → 一般 → キーボード → 音声入力」をオンにし、マイクを許可してください
- 読み上げの声は「設定 → アクセシビリティ → 読み上げコンテンツ → 声 → 英語」で高音質の声（拡張・プレミアム）を追加すると自然になります
- Pixel / Android の Chrome でも動きます（Google の音声で読み上げ・認識）

> 学習記録は端末のブラウザ内（localStorage / IndexedDB）に保存されます。Safari の「履歴と Web サイトデータを消去」で消えるため、
> 設定画面の「バックアップを保存」でときどき書き出してください（API キーはバックアップに含まれません）。

## AI の設定

### アプリ内蔵AI（利用者の設定は不要）

アプリには **Modellix の無料 LLM（`modellix-ai/free-llm`）** があらかじめ組み込まれていて、利用者は何も設定せずに
「AIにくわしく聞く」「AI添削」「AIで採点」「AIで問題を作る」を使えます。

```
アプリ（GitHub Pages）→ AI 中継（Cloudflare Worker：proxy/）→ Modellix LLM
```

- Modellix の API はブラウザから直接呼べない（CORS 非対応）ので、`proxy/` の Cloudflare Worker が中継します
- **API キーは Cloudflare の Secret にだけ保存**し、アプリのコードや GitHub には入れません
- 中継サーバーでは、許可したサイトからの呼び出しだけを受け付けます。モデルと出力トークン数も固定し、IP ごとの回数制限（1分12回）をかけています
- 接続先は `js/config.js` の `BUILTIN_AI`（Worker の URL＋`/v1` とモデル名）で指定します
- 公開・キー登録・設定の変更は [proxy/README.md](proxy/README.md) を参照してください
- 料金：無料モデルなので 0 円（Modellix の使用量でも cost 0 を確認済み）。中で複数の AI に振り分けられるため、回答の質や速さ（解説10〜20秒・採点20〜30秒）にばらつきがあります
- 中身のない返答や混雑のときは、中継サーバーが自動でやり直します（`RETRIES`）
- 有料モデルに切り替えるときは、`proxy/wrangler.toml` の `ALLOWED_MODELS` を変えて deploy します（例：`deepseek/deepseek-v4-flash`。英作文の添削1回で約0.2円）

### クレジットを節約するしくみ

- **回答の保存**：同じ問題・同じ答案への回答は IndexedDB に保存し、2回目からは AI を呼びません
- **AI なしでも動く**：解説（全問に日本語解説つき）・英作文の自動チェック・面接の自動採点はすべて端末内で動きます。AI を使うのはボタンを押したときだけです
- **出力を短く**：採点は JSON で返させ、小さなモデルでも安定するようにしています

### 自分の AI を追加する（任意）

設定 →「AI」で、内蔵AIの下に OpenAI 互換の接続先を追加できます（上から順に試し、失敗したら次へ）。

| 接続先 | URL の例 | モデルの例 |
|---|---|---|
| 自前サーバー（Oracle Cloud の Gemma など） | `https://your-server/v1` | `gemma3:12b` |
| OpenRouter | `https://openrouter.ai/api/v1` | 「モデル一覧」で料金つきの一覧を取得 |

自前サーバーを使うときは、HTTPS 化と CORS の許可（Ollama なら `OLLAMA_ORIGINS`）が必要です。
自分で登録した API キーはその端末の中だけに保存され、バックアップファイルには含まれません。

## 手書き判定のしくみ

`js/recognizer.js` / `js/spell.js`

1. **オンライン**：Google 手書き入力 API に**1マスずつ別々に**線の座標を送り、返ってきた候補の上位に正解の文字があるかで判定（`l` と `1`、`o` と `0` などの取り違えは同じ文字とみなす）
2. **オフライン**：アルファベットのお手本（`js/letters.js`）と $P 点群認識で照合し、4線のどこに書いたか（上に出る・下に出る）と i / j の点も手がかりにする簡易認識
3. **自分で判定**：お手本と見比べて ○／× をつける

認識ミスのときは答え合わせで「読み取りミス（正しく書けていた）」を押すと記録を直せます。
「自動」では書いた線の座標データが Google に送信されます。送信したくない場合は設定で「端末内のみ」を選んでください。

## 開発

```bash
npm start
```

`http://localhost:8766` で確認できます（Service Worker は localhost か HTTPS でのみ動きます）。

```bash
npm run check
```

問題データを検証します（選択肢の数・重複・空所・例文の { }・模範解答の語数など）。

### 問題を追加・修正する

- 単語・熟語・会話表現：`data/words.js`（1行＝`単語|品詞|意味|例文（{ }が見出し語）|訳|重要度|変化形`）
- 大問1・2：`data/reading.js`（1行1問・選択肢は正解を先頭に書く。出題時にシャッフル）
- 長文・リスニング・ライティング・面接：それぞれ `data/` の各ファイル

問題の ID は問題文から作るハッシュなので、問題文を変えるとその問題の学習記録はリセットされます。
追加・修正したら `npm run check` で検証してください。

### 公開のしかた

静的ファイルだけなので、GitHub Pages・Netlify・Cloudflare Pages などにフォルダごと置けば動きます（HTTPS が必要）。
ファイルを更新したら `sw.js` の `VERSION` を上げると、アプリ内に「新しいバージョンがあります」と表示されます。

## 注意

- 問題・例文はすべて本番の出題形式にならったオリジナルです。過去問の転載ではありません
- 英検の過去問（直近3回分）は日本英語検定協会の公式サイトで公開されています。「筆記 → 問題をふやす → 取り込む」で自分の学習用に追加できます
- CSE スコアは正答率からの換算による目安です（実際の CSE は統計的に算出されます）
- 本アプリは公益財団法人 日本英語検定協会とは関係ありません
